# Joinlet interface

The editor uses React, TypeScript, React Flow and reusable application components. Diagram meaning and layout are stored separately. Documents use Markdown and sketches use Excalidraw.

Use the existing theme tokens, accessible contrast, keyboard interaction and focus patterns. Public naming is Joinlet; existing technical identifiers remain compatible. The Jo mascot and bundled brand assets follow `TRADEMARKS.md`; internal generation prompts are not delivery assets.

Keep descriptions faithful to implemented behavior. The application supports browser, folder, GitHub and hosted storage through adapters. Cloud account access is enforced by the server. Architecture editing does not automatically rewrite arbitrary source code.

Use the product architecture in `.arch/` and the existing tests when changing behavior. Record decisions in public product documentation without including private workspaces, personal machine paths, credentials or internal operational notes.
