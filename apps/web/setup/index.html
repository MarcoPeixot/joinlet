Connect AI to Joinlet.

The visual editor runs in your browser without an account. To use AI, run the Joinlet server on your computer and connect your own provider.

1. Prepare your computer

You need a copy of the Joinlet project, Node.js 22.4 or later, and Bun 1.4 or later. Open a terminal in the project directory, where its package.json file is located.

2. Start Joinlet

bun install
bun run dev

Keep the terminal open. Open localhost:5178/app/ on the same computer. The editor and its local API start together.

3. Connect a provider

Open Settings → AI and providers, choose a service, save your API key and select Test connection. For Ollama or LM Studio, start its compatible API server and select it under OpenAI-compatible. Select the model you want to use.

Workspaces are stored per browser origin. To move work from joinlet.co to localhost, export the workspace ZIP from the website and import it into your local editor.

Troubleshooting

  • Server unavailable: check the terminal and restart bun run dev.
  • Invalid key: create a key with your provider, save it again and test the connection.
  • Model unavailable: select a model available to your provider account.

Keys remain on the local server. Provider usage and billing follow your own provider account. Drawing, documents and local saving remain available without AI.

Conecte IA ao Joinlet.

O editor visual funciona no navegador, sem conta. Para usar IA, execute o servidor do Joinlet no seu computador e conecte seu próprio provedor.

1. Prepare o computador

Você precisa de uma cópia do projeto Joinlet, Node.js 22.4 ou superior e Bun 1.4 ou superior. Abra um terminal na pasta do projeto, onde fica o arquivo package.json.

2. Inicie o Joinlet

bun install
bun run dev

Mantenha o terminal aberto e acesse localhost:5178/app/ no mesmo computador. O editor e a API local iniciam juntos.

3. Conecte um provedor

Abra Configurações → IA e providers, escolha um serviço, salve a chave e clique em Testar conexão. Para Ollama ou LM Studio, inicie o servidor de API compatível e selecione-o em Compatível com OpenAI. Escolha o modelo que deseja usar.

Cada endereço mantém seu próprio armazenamento no navegador. Para levar o trabalho de joinlet.co ao localhost, exporte o ZIP do workspace no site e importe no editor local.

Se algo não funcionar

  • Servidor indisponível: verifique o terminal e reinicie bun run dev.
  • Chave inválida: crie uma chave no provedor, salve novamente e teste a conexão.
  • Modelo indisponível: escolha um modelo disponível na sua conta do provedor.

As chaves ficam no servidor local. O uso e a cobrança seguem sua conta do provedor. Desenhos, documentos e salvamento local continuam disponíveis sem IA.
