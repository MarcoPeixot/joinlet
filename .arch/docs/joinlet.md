# Joinlet

Joinlet helps developers, architects and engineering teams draw, document and version software architecture, and provide architectural context to coding agents.

The application includes a visual canvas, diagrams as text, Markdown documents, sketches, comments, version comparisons, import/export, AI assistance, CLI and MCP integration. Workspaces can live in browser storage, a local folder, a GitHub repository or the hosted backend.

The open-source application can be self-hosted under its license. Joinlet Cloud provides a managed deployment. Local/self-hosted use has no commercial quotas; the managed Cloud currently uses Free Beta and administrator policies, and AI uses the account's own provider key. Paid subscriptions are future work, not an implemented feature.

Do not claim universal source-code synchronization, automatically generated application code, production service availability, customer adoption or commercial plans beyond verified behavior.
